# Code Review Skill

Use this skill when reviewing source code before implementation.

## Review categories
1. Correctness bugs
2. Data loss risks
3. Error handling
4. Performance bottlenecks
5. Maintainability
6. Missing tests

## Output format
- Finding
- Evidence from code
- Severity: high/medium/low
- Suggested fix
- Test needed

## Rules
- Do not modify code during review.
- Do not suggest large refactors unless clearly justified.
- Prefer small patches.
